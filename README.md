Página Pessoal - André Roger Nogueiro Dias

Página pessoal feita com HTML e CSS, onde eu me apresento, conto algumas curiosidades sobre mim e mostro os lugares que já conheci e os que desejo conhecer.

Sobre o projeto

A página tem as seguintes seções:

Curiosidades: lista com informações sobre mim, meus gostos e minha rotina.
Lugares - Já fui: Portugal, Gramado e Bahia, com foto e um texto sobre cada viagem.
Lugares - Desejo conhecer: Japão, Inglaterra e Bariloche, com foto e o motivo de querer ir.
Links de navegação: voltar para o topo da página e para a página inicial.
Tecnologias
HTML5
CSS3 (Grid, position, unidades relativas e media query)
Recursos de CSS usados
display: grid para organizar a página em 2 colunas
position: sticky no título
Unidades relativas como rem e %
Responsividade com @media (max-width: 600px), que volta o layout para 1 coluna no celular
Paleta de cores
